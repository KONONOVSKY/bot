# TOP TEAM bot — запуск (GitHub → Render)

## 1. Файлы в репозитории GitHub
`bot.py`, `requirements.txt`, `README.md` (замените старый bot.py, нажмите Commit — Render перезапустится сам).

## 2. Переменные окружения на Render (Environment)
| Имя | Значение |
|---|---|
| `BOT_TOKEN` | НОВЫЙ токен от @BotFather (старый засвечен в переписке — сделайте /revoke) |
| `CHAT_ID` | `-1002034080349` (ID рабочего чата из вашего экспорта; если бот молчит — удалите переменную, бот запомнит чат сам по первому сообщению) |

Start Command: `python bot.py`. Build Command: `pip install -r requirements.txt`.

## 3. ОБЯЗАТЕЛЬНО в Telegram
1. @BotFather → `/mybots` → ваш бот → Bot Settings → Group Privacy → **Turn off**.
2. Сделайте бота **администратором** группы (хватит права «Закреплять»/любого минимального) — иначе он не увидит отчёты и реакции людей на фото.
3. Если бот уже был в группе — удалите и добавьте заново после смены Privacy.

## 4. Чтобы бесплатный Render не засыпал
Создайте монитор на uptimerobot.com: HTTP(s), URL вашего сервиса на Render, интервал 5 минут.

## Правила бота (меняются в начале bot.py)
- Текстом пишет только с 07:30 до 18:00 (`SPEAK_FROM`, `SPEAK_UNTIL`). Реакции на вечерние отчёты — без текста.
- Шутка/совет каждый час: 10:20, 11:20, 12:20, 13:30, 14:20, 15:20, 16:20, 17:20. После 4 сообщений подряд без ответа людей — пауза.
- Молчит 45 мин после жалоб на 1С/связь, час после «Свет −/Генератор», 3 часа после сборов/прощаний.
- Итоги вчера — в 09:30, итоги недели — по понедельникам в 09:30.
- Команды: /top /today /joke /help
